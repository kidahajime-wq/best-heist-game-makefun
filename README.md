**The Gilded Gala** — a top-down heist game set in the Aurum Casino on gala night. Slip through the gala floor in a borrowed tuxedo, read the guards' vision cones, mind the sweeping cameras, lift the Star of Aurum diamond from the vault, and escape through the service exit before the clock — or the alarm — runs out. Loot weighs you down, a power cut blinds the cameras, and Marcel the insider will open the vault door once. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Play with keyboard and mouse: WASD / arrows to move, SHIFT to sprint (loud), C to crouch (quiet), Q for a power cut, E for the insider, M to mute, R to restart.
